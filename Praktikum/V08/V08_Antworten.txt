b) Test auf Vorlesungsgraph (Start a)
- a: Distanz=0, Pfad=a
- b: Distanz=7, Pfad=a -> d -> c -> b
- c: Distanz=2, Pfad=a -> d -> c
- d: Distanz=4, Pfad=a -> d
- e: Distanz=6, Pfad=a -> d -> e
- has_negative_cycle: False

c) Negativer Zyklus
- Zusatzkante: e -> b mit Gewicht -8
- has_negative_cycle: True
- Betroffener Zyklus: b -> d -> e -> b
- Zyklusgewicht: -4

d) Komplexitaet
- Bellman-Ford: O(|V|*|E|)
- Dijkstra (Min-Heap): O(|V| log |V| + |E|)
- Dijkstra bei nicht-negativen Kanten, Bellman-Ford bei negativen Kanten/Zyklenpruefung.
