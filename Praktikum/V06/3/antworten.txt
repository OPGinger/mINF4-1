3b) Why continue search on DELETED but stop on UNUSED?
DELETED means this slot was part of a probe chain in the past, so the key
might still appear later in the same chain. UNUSED means no key has ever
been placed at this probe position, so the chain ends and search can stop.

3c) What breaks if delete sets UNUSED instead of DELETED?
Concrete example with m=20: choose x=52 and y=-984 with h(x)=h(y)=2.
Insert x first, then y. y is stored at a later probe position.
If x is deleted and marked UNUSED, searching y stops too early at x's old slot
and incorrectly returns False. So search becomes faulty.
