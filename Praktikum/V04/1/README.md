# Task 1 - Visualization with Graphviz

## Goal
Load `seq0.txt`, insert all values into a Binary Search Tree, call `graph_traversal()`, and answer:
- Which node is the root?
- How many leaf nodes are in the tree?
- What is the height of the tree?

## Files
- `aufgabe1_visualisierung.py`: main implementation.
- `antworten.txt`: final answers.
- `BinaryTree_*.gv.pdf`: generated Graphviz output.

## Run
From this folder:

```powershell
& "../../.venv/Scripts/python.exe" "aufgabe1_visualisierung.py"
```

The script writes all output artifacts into this folder.
