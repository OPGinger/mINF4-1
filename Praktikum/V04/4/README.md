# Task 4 - Deletion in AVL Tree

## Goal
Demonstrate deletion in AVL trees and verify that balancing is preserved.

## Method
- Insert a deterministic sequence.
- Export AVL graph before deletion.
- Delete selected nodes.
- Export AVL graph after deletion.
- Compare heights and in-order traversal.

## Files
- `aufgabe4_avl_loeschen.py`: implementation.
- `antworten.txt`: measured values and interpretation.
- `AVL_Before_Delete_*.gv.pdf`: graph before deletion.
- `AVL_After_Delete_*.gv.pdf`: graph after deletion.

## Run
From this folder:

```powershell
& "../../.venv/Scripts/python.exe" "aufgabe4_avl_loeschen.py"
```
